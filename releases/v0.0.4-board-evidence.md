## Performance samples

Install frozen workspace dependencies for each source, build the UI into `server/ui-dist`, and start an isolated local-trusted test instance with embedded PostgreSQL and fixture data. Use the same candidate fixture and browser for both source builds. Set `PROPRIO_ISSUE_PERF_BASE_URL` to the disposable loopback origin and `PROPRIO_TASK_OPEN_BUILD` and `PROPRIO_TASK_OPEN_OUTPUT` to the tested SHA and an output path. Run `task-open-cohorts.spec.ts` with the [issue-detail Playwright configuration](../tests/perf/issue-detail/playwright.config.ts).

A ready sample has both the most recent message and the composer visible. Readiness is the later of those two timestamps. Samples are in attempt order within each cohort.
